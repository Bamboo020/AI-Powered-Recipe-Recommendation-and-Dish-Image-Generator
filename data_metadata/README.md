# Data provenance

`demo_recipes.json` contains six project-authored illustrative fixtures, authored during implementation with AI assistance. They are not imported Food.com samples, have no external source URL, and have not been independently reviewed for culinary accuracy or food safety. They are for functional testing only.

Each record explicitly carries provenance and quality flags. Do not relabel them as public dataset records or validated recipes. No dataset images are included.

Real-data import must preserve source dataset ID and provenance, validate ingredient/step/time fields, identify missing times, distinguish cooked rice from raw rice, and document applicable dataset terms before redistribution. There is no dataset importer in v0.1.
