# 课堂要求核对（2026-11-17）

依据用户提供的 14 天指南转述，**不是教授评分标准原文，也不是 TA 的认可证明**。

| 指南中的要求 | 当前证据 | 判断 |
| --- | --- | --- |
| Web / Mobile、有 UI/UX | React 响应式页面，FastAPI，食材及照片入口 | 技术上已实现 |
| 至少四个课程 Topics | ResNet18 CNN、nomic 编码器 Transformer、Qwen LLM、Stable Diffusion | 四个模型模块已运行；Topics 如何计数仍需 TA 确认 |
| 真实数据 | 下载完整 Food.com 和 Food-101；5,106 条真实食谱接入应用；5 类真实图像参与训练/测试 | 已补齐，但不是完整 101 类分类器 |
| CNN 与图片识别流程 | 五类迁移学习头、Top-3、用户确认/纠正、相关食谱检索 | 已实现限定范围；类别映射仍是启发式 |
| 模型评估 | 独立官方测试集指标、混淆矩阵、推荐基线比较、提供方烟测 | 已有实测；人工相关性和生成质量评估仍需加强 |
| 可现场演示 | 本机数据/权重配置、启动说明、接口烟测、页面上传验证 | 原型可运行；仍需团队在演示环境复核 |
| 三人团队、分工、最终报告/演示与提交包 | 当前聊天不能证明成员或完成这些交付 | 团队仍需完成 |
| 指南转述 AI 仅限选题/UI/架构 | 当前实际使用 AI 编码、配置和训练脚本 | 与转述规则有冲突；用户此前要求忽略规则不等于教授许可 |

因此可以说：**技术缺口已显著补齐，但不能保证“完全符合课堂要求”或保证评分。** 最终还需原始课程文件、TA 对 Topics 与 AI 用途的许可、团队材料和独立演示验收。不能把预训练 CNN 的分类头迁移学习说成从零训练完整 CNN，也不能把五类测试准确率说成 101 类准确率。
