Pantry Studio v0.1
See README.md for full setup.
Python 3.11+, Node 20.19+ or 22.12+.
Backend: cd backend; create/activate a virtualenv; pip install -r requirements.txt; python -m uvicorn app.main:app --reload
Frontend (second terminal): cd frontend; npm ci; npm run dev
Browser: http://localhost:5173
API documentation: http://127.0.0.1:8000/docs
No API keys are required for this fixture-based version. AI providers are not yet configured.
